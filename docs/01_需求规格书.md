## 0. 依据与设计范围

**依据材料**

1. 《1.2 需求分析》表（功能/性能/平台三类需求）。
2. 《基于 ZYNQ-7010 的多运动目标检测与颜色识别追踪系统》立项方案，其中**考核指标**为本规格的硬约束来源。
3. 《EBAZ4205 + 教学扩展板硬件说明》（引脚、时钟、电平、复用冲突）。

**范围界定**

- 纯 PL 逻辑实现：不使用 PS、不使用 DDR3/VDMA、不使用软核 CPU。整条图像流水线为硬件流水，单像素/单块节拍推进。
- 用户交互仅用扩展板 4 按键 + 4 LED + VGA 屏幕 OSD，不依赖上位机。
- 五个颜色：**红 RED / 绿 GREEN / 蓝 BLUE / 黄 YELLOW / 紫 PURPLE**（瓶盖模拟）。

**范围外（本期不做，写入扩展需求）**

- 目标计数统计、轨迹绘制、卡尔曼滤波完整实现（仅保留"匀速预测"轻量版）、更高分辨率（1280×720）。

## 1. 功能需求（F）

| 编号 | 需求 | 实现要点 | 验证方法 |
|---|---|---|---|
| F1 | OV5640 实时采集 | DVP 8bit，RGB565，640×480@30fps；PCLK 域采集 + 异步 FIFO 跨域 | 直显画面无花屏/无错位 |
| F2 | SCCB 配置摄像头 | I2C 主机 + 寄存器配置 ROM；**开启 AWB/AEC**，关闭镜头暗角校正以外的后处理 | 上电 200ms 内出图 |
| F3 | 运动目标检测 | 4×4 像素块降采样为 160×120 网格，块内亮度求和；与上一帧块亮度做差分 + 阈值 → 块级运动掩膜 | 静止画面无框，移动瓶盖出框 |
| F4 | 颜色分类 | 每个 4×4 块内做 5 类颜色投票（16 像素中胜出类别需 ≥6 票），输出块颜色类别（3bit：0=背景，1~5=五色） | 五色色卡逐色测试 |
| F5 | 多目标分离 | **块级单遍 4 邻域连通域标记**（并查集）：同色且空间相邻的块合并为同一目标，从而把同色的 2 个瓶盖分成 2 个目标 | 同屏 2 个同色目标出 2 个独立框 |
| F6 | 目标筛选与容量 | 面积门限（≥12 块）滤除噪点；每帧最多输出 **16 个**目标 | 10 目标场景全框出 |
| F7 | 框选显示 | 每个目标绘制 2px 边框，**边框颜色 = 目标颜色**；边框在 VGA 叠加层生成（不写回图像缓存） | 目视核对 |
| F8 | 目标 ID | 帧间质心最近邻匹配（距离门限 24 块），匹配成功继承 ID，否则新建 | 目标慢速移动 ID 不跳变 |
| F9 | 单色持续追踪 | 在选定颜色的目标中取面积最大者作为追踪对象；**丢失保持**：连续丢帧 ≤15 帧（0.5s）内框保留在最后位置并按速度外推 | 遮挡 0.5s 内不丢框 |
| F10 | 按键控制 | key1/key2：追踪颜色 +/-（五色循环）；key3：单色追踪模式开关；key4：五色全识别框选开关；两模式互斥，均关闭则原图直显 | 按键测试矩阵 T4 |
| F11 | VGA 输出 | 640×480@60Hz，RGB565，像素时钟 25.2MHz；图像 320×240 帧缓存 2×2 放大显示 | 显示器稳定无抖动 |
| F12 | OSD 信息 | 五色图例色块、当前选中颜色高亮、模式文字（ALL / SINGLE / OFF）、目标 ID 数字、实时帧率 | 目视 |

**按键与显示状态机（F10 细化）**

| 当前状态 | key4 按下 | key3 按下 | key1 / key2 |
|---|---|---|---|
| OFF（原图直显） | → ALL | → SINGLE | 切换选中颜色（暂不显示框，OSD 图例高亮变化） |
| ALL（五色全框选） | → OFF | → SINGLE | 切换选中颜色（ALL 模式下仅高亮图例） |
| SINGLE（单色追踪） | → ALL | → OFF | 切换追踪颜色，追踪框立即切换 |

**LED 指示（扩展板低电平点亮，one-hot 取反使用）**

- LED0：ALL 模式亮；LED1：SINGLE 模式亮。
- LED2/LED3：二进制显示当前选中颜色索引（红=00，绿=01，蓝=10，黄=11，紫=00 循环需另加闪烁；实际用 LED2 单色点亮 + OSD 图例区分主色）。

## 2. 性能需求（P）

| 编号 | 指标 | 目标值 | 测量方法 |
|---|---|---|---|
| P1 | 处理帧率 | ≥ 30 fps | 帧计数器（1s 闸门）显示于 OSD |
| P2 | 端到端延迟 | ≤ 2 帧（≈67ms），远小于 0.5s | LED 打点 + 示波器 / 高速手机录像 |
| P3 | 颜色分类准确率 | ≥ 90%（标准室内光照，5 色 × 每色 ≥2 目标） | T1/T2 测试，人工计数 |
| P4 | 追踪稳定性 | 连续 10s 不丢框、不漂移（目标在视野内匀速移动） | T3 录像计时 |
| P5 | 多目标容量 | 同帧 ≥10 目标、≥5 色、每色 ≥2 | T2 |
| P6 | 光照鲁棒性 | 照度 300~800 lux 范围内分类准确率下降 ≤10 个百分点（软指标） | 调光灯 + 三次采样 |
| P7 | 资源占用 | LUT < 80%；BRAM ≤ 80%；时序 WNS ≥ 0 | Vivado report |

## 3. 平台与接口（H）

| 项 | 规格 | 引脚/说明 |
|---|---|---|
| 主时钟 | 50MHz（X5 已焊） | N18，`create_clock -period 20.000` |
| 派生时钟 | 100MHz（系统处理）、25.2MHz（VGA 像素） | MMCM，1 个 CMT |
| 摄像头时钟 | OV_XCLK 24MHz 由 PL 输出；PCLK 由 CC 提供（24~48MHz） | XCLK=F20，PCLK=E19 |
| PCLK 特殊处理 | E19 非专用时钟引脚 | XDC 需 `set_property CLOCK_DEDICATED_ROUTE FALSE` |
| 按键 | KEY1=G19 / KEY2=J19 / KEY3=K19 / KEY4=L16，10K 上拉，低有效 | 20ms 消抖 + 上升沿检测 |
| LED | H20/K18/J20/L19，低电平点亮 | 2K 限流 |
| VGA | RGB565 + HSYNC(U20)/VSYNC(V20) | 电阻网络 DAC |
| 复位 | **板上无复位按键** | 上电复位（POR，计数器 1ms）+ 可选 key1+key2 长按 2s 软复位 |
| 复用冲突 | A20 = OV_RESET 与 PL-UART RX 二选一 | 本设计固定用 OV_RESET，UART 不使能 |
| UART | P6 排针（可选调试口，输出帧率/目标数） | 二期可选 |

## 4. 关键设计决策（D）—— 待确认

### D1 显示通道与帧缓存

| 方案 | 做法 | BRAM | 画质/现象 |
|---|---|---|---|
| **A1（推荐）** | 320×240 RGB565 单帧缓存，VGA 端 2×2 放大 | 34/60（57%） | 画质好，帧边界可能出现 1 条撕裂线 |
| A2 | 320×240 RGB332 双缓冲 | 34/60 | 无撕裂，但颜色量化严重（紫/蓝难分辨），影响 P3 目视判定 |
| B | PS + DDR3 + VDMA，640×480 全分辨率 | ≈0 | 画质最好、无撕裂，但需 PS 配置与 FSBL/BOOT，超出"纯 PL"范围 |

**推荐 A1**：考核要靠肉眼判断"框色=物色"，画质优先；撕裂线不影响识别结果与指标测量。若演示时不能接受撕裂，升级路径为 B（架构上留好 AXI 位置）。

### D2 多目标分离算法

| 方案 | 能否分离同色多目标 | 复杂度 |
|---|---|---|
| **块级单遍 CCL（推荐）** | 能（这是满足"每色 ≥2 目标"的唯一途径） | 中，约 2.5~3K LUT |
| 行列投影直方图 | 不能（同色 2 目标并成 1 框） | 低 |
| 像素级 CCL（640×480） | 能 | 高，需标签帧缓存，BRAM 不够 |

**推荐块级 CCL**：4×4 降采样后网格 160×120，标签行缓冲仅需 2×160×8bit，标签总数 256（并查集表 256×8bit）。分辨率损失 4 倍，对"瓶盖级"目标（约 27px ≈ 7×7 块）无影响。

### D3 颜色分类方法

| 方案 | 资源 | 鲁棒性 |
|---|---|---|
| **通道比较 + 比值（推荐）** | 仅加法器/比较器，无除法、无 DSP | 配合"块内投票"与 AWB，标准光照足够 |
| RGB→HSV（CORDIC/除法器） | 需除法器，~1.5K LUT 或 4~8 DSP | 更好，但调试成本高 |
| 3D LUT | BRAM 消耗大 | 好但不可解释，不便于现场调阈值 |

**推荐通道比较法 + 块内投票**：单像素误判由 16 像素投票抹平，等效获得了与 HSV 相近的鲁棒性，且阈值寄存器可直接暴露给现场调试（串口/按键），便于答辩现场调参。

### D4 运动检测粒度

统一采用 **4×4 块级**（与 F3/F4 共用同一套块流水线），像素级帧差需要 640×480 灰度前帧缓存（300KB > BRAM 容量），不可行。

### D5 时钟域划分

| 时钟域 | 频率 | 承载逻辑 |
|---|---|---|
| PCLK 域 | 24~48MHz（CC 提供） | DVP 采集、4×4 块累加与颜色投票 |
| clk_sys | 100MHz | CCL、连通域统计、匹配追踪、按键/OSD 逻辑 |
| clk_pix | 25.2MHz | VGA 时序、帧缓存读、叠加层 |
| clk50 | 50MHz | SCCB、POR、慢速控制 |

每行 160 块，CCL 在 100MHz 域可用 ~1300 时钟/行处理 160 块（≈8 时钟/块），BRAM 读改写余量充足。

## 5. 资源与可行性初评（impl-engineer 视角）

**BRAM（总量 60 × 36Kb = 2160Kb）**

| 用途 | 算式 | 占用 |
|---|---|---|
| 显示帧缓存 320×240×16b | 1,228,800 / 36,864 = 33.3 | 34 |
| 前帧块亮度 19200×8b（2 块/18Kb 打包） | 153,600 / 18,432 ≈ 8.3 | 5 |
| 并查集表 + 联通统计 256×64b | 16,384 | 1 |
| 目标表 16×96b（双缓冲） | 3,072 | 1 |
| 字模 ROM 8×16 ASCII | 16,384 | 1 |
| 行缓冲/FIFO | — | 2 |
| **合计** | | **≈44 / 60（73%）** |

**其他资源**

- LUT：估 11~13K / 17,600（**63~74%，风险项 R2**），主要消耗：CCL 2.5K、统计 2K、追踪 1.5K、VGA+OSD 2K、块流水 2K。
- DSP：≈4（距离平方复用 1 个乘法器）。
- FF：估 9~11K / 35,200。
- CMT：1 个 MMCM（7010 共 2 个）。

**时序**

- 主频最高 100MHz，最高扇出路径为 CCL 并查集访问，预计关键路径 7~9ns，-1 速度等级 100MHz（10ns）可收敛但余量小；若失败则 CCL 改 50MHz + 每块 4 拍流水。**此为 Phase 4 主要收敛风险。**

## 6. 风险清单

| 编号 | 风险 | 等级 | 缓解措施 |
|---|---|---|---|
| R1 | BRAM 73% 偏紧 | 中 | 优先级：文字改小字库→目标表减至 12 个→最后才降 RGB332 |
| R2 | LUT 63~74% 预估偏差 | 中 | CCL 复用同一 ALU 分时；块网格可退化为 8×8（80×60） |
| R3 | PCLK 走非专用时钟脚 | 高（必现） | XDC 加 `CLOCK_DEDICATED_ROUTE FALSE` + 手动 BUFG，Phase 3 必须验证 |
| R4 | 单缓冲帧撕裂 | 低 | 接受；备选 A2/B |
| R5 | 同色目标物理粘连（两瓶盖挨在一起） | 中 | 块级形态学腐蚀（3×3 块邻域内同色块数 ≥3 才保留）+ CCL 分离 |
| R6 | 无复位按键 | 低 | POR + 组合键软复位 |
| R7 | 光照突变导致阈值失效 | 中 | OV5640 AWB/AEC + 阈值寄存器在线可调 + 亮度归一化（用帧平均亮度做阈值补偿） |
| R8 | 50MHz 晶振与资料差异 | 已排除 | 原理图确认 X5=50MHz，N18 约束 20ns |
| R9 | 紫色与蓝色在 RGB 空间距离近 | 中 | 紫色判据额外要求 R 与 B 同时高于 G；阈值现场标定，必要时加"紫色优先"判决顺序 |

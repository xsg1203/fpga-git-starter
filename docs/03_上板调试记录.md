# 上板调试记录 · M2（采集直显）

> 阶段：M2 采集链路验证
> 目标：VGA 上出现 OV5640 实时画面
> 状态：⏳ 待上板

---

## 1. 上电顺序

1. 断电插好扩展板、OV5640 模块、VGA 线。
2. 确认电源极性与电压（VCC_IN 5V），**反接会烧核心板**。
3. 上电，接 JTAG，Program Device 下载 `ct_ebaz4205.bit`。
4. 按下表读 LED，再看屏幕。

## 2. LED 判读（低电平点亮）

| LED3 | LED2 | LED1 | LED0 | 含义 | 下一步 |
|---|---|---|---|---|---|
| 灭 | 亮 | 亮 | 亮 | 全部正常，应已出图 | 看屏幕；无图则查 VGA 线/显示器输入源 |
| 灭 | 灭 | 亮 | 亮 | 配置完成但**收不到 VSYNC** | 查 XCLK/PCLK/复位；见 §4 |
| 灭 | 灭 | 灭 | 亮 | SCCB 配置卡住 | 查 SCL/SDA 上拉与接线；见 §4.1 |
| **亮** | x | x | 亮 | SCCB 出现无 ACK | 说明 SDA 未被从机拉低：接线/上拉/地址 |
| x | x | x | 灭 | MMCM 未锁定 | 时钟或约束问题，先看 implement 报告 |

## 3. 屏幕现象速查

| 现象 | 最可能原因 | 处置 |
|---|---|---|
| 全黑，无任何同步（显示器"无信号"） | VGA 时序/RGB 线序；或 vsync/hsync 极性反 | 先确认 U20/V20 接线；把 `vga_timing.v` 的 hsync/vsync 取反试一次 |
| 有信号但画面纯色/纯黑 | 帧缓存没写进去：pix_vld 不来（HREF 无）或写地址错 | 用 ILA 抓 `pix_vld / cx / cy / wr_en` |
| 画面能出但整体偏色 | RGB565 字节序反了 | 把 `ov5640_capture.v` 里 `{b1,data}` 改 `{data,b1}` |
| 画面上下/左右反了 | 镜像位不对 | 改 `0x3820 / 0x3821` |
| 画面斜条纹/错位 | PCLK 采样相位不对 | 试在 pclk 上反相采样，或降 PCLK（改 0x3035/0x3036） |
| 画面正常但有一条横向撕裂线 | 单缓冲帧边界（已知，方案 A1 接受） | 无需处理 |
| 画面比例变形 | 摄像头窗口不是 4:3 | 核对 `0x3808~0x380B` = 640×480 |

## 4. 分步定位

### 4.1 SCCB 是否通
- 用示波器看 `J18(SCL)`：应有约 195kHz 的 27 个时钟簇，每簇之间 40us 间隔。
- 看 `G20(SDA)`：SCL 低期间变化；第 9 个时钟应被从机拉低（ACK）。
- LED3 亮 = 没有 ACK：先量 SDA/SCL 静态电平，**空闲都应为 3.3V**。若为 0V 或悬空，检查模块板上 4.7K 上拉是否装配。

### 4.2 摄像头是否在出图
- 量 `F20(XCLK)`：应有 25MHz 方波。没有 → 引脚/位流问题。
- 量 `E19(PCLK)`：配置成功后应有 20~50MHz 方波。没有 → 配置没生效（回到 4.1）。
- 量 `K17(VSYNC)`：应有约 30Hz 正脉冲。没有但 PCLK 有 → 窗口/VTS 配置问题。

### 4.3 打开传感器自测图案
把 `rtl/ov5640/ov5640_cfg.v` 第 `8'd63` 条改成：
```verilog
8'd63: cfg_rom = {8'h50, 8'h3D};   // 0x82 = 彩条
```
重新综合下载。**彩条能显示** ⇒ 采集/缓存/VGA 链路全部正常，问题只在颜色格式或镜头；**彩条也不显示** ⇒ 问题在 `0xd3` 之后的采集或显示链路，与传感器无关。这一步能把问题一分为二，务必先做。

## 5. 已知需现场核对的寄存器

| 寄存器 | 当前值 | 作用 | 不对时的现象 |
|---|---|---|---|
| 0x4300 | 0x6F | 输出格式 RGB565 | 偏色 / 像 YUV |
| 0x3035/0x3036 | 0x21 / 0xA1 | PLL，决定 PCLK | PCLK 频率不对，画面斜纹 |
| 0x380C/0x380D | 0x07/0x68 | HTS | 帧率/行数不对 |
| 0x380E/0x380F | 0x02/0x78 | VTS | 帧率不对 |
| 0x3820/0x3821 | 0x46/0x46 | 镜像翻转 | 画面反 |
| 0x503D | 0x00 | 测试图案 | — |

> 若四项都调不通，直接换成你手上教程/厂商给的完整初始化表：只需替换 `cfg_rom` 的 case 内容，`{reg, data}` 两字节格式不变，序列器不用动。

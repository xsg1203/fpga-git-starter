## 1. 三级层次划分

```
系统层  ct_top                     —— 时钟/复位、域连接、外设绑定
子系统层
  ├─ video_in    采集子系统         ov5640_capture + framebuf_wr
  ├─ vision      视觉算法子系统     block_stat / motion / ccl / comp_stat / tracker
  ├─ video_out   显示子系统         framebuf_rd + vga_timing + overlay + osd
  └─ ctrl        人机子系统         key_debounce + mode_fsm + cfg_seq
模块层  各 .v 单文件，接口见 §3
```

**分层原则**：子系统之间只通过"帧同步脉冲 + 目标表 + 像素流"三类信号交互，禁止跨层直连内部寄存器。这样 M3~M5 增加算法模块时，video_out 与 ctrl 完全不用改。

---

## 2. 时钟与复位

| 时钟 | 来源 | 频率 | 承载 |
|---|---|---|---|
| clk50 | N18 晶振 | 50MHz | POR、SCCB 配置 |
| clk_sys | MMCM CLKOUT0 | 100MHz | 块帧差、CCL、统计、追踪、按键 |
| clk_pix | MMCM CLKOUT1 | 25MHz | VGA 时序、帧缓存读、叠加 |
| ov_pclk | OV5640 E19 | 24~48MHz（随寄存器） | DVP 采集、4×4 块累加 |

MMCM 配置：`DIVCLK=1, MULT=18.000 → VCO 900MHz`；`CLKOUT0_DIVIDE_F=9.000 → 100MHz`；`CLKOUT1_DIVIDE=36 → 25MHz`。25MHz 同时作为 OV_XCLK，避免额外小数分频（640×480@25.0MHz 刷新 59.5Hz，全兼容）。

**复位**：板上无复位键 → `por_reset` 产生 1.3ms 上电复位；每个非 clk50 域经 `rst_sync` 做"异步复位、同步释放"。

## 3. 模块接口表

### 3.1 video_in 子系统

| 模块 | 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|---|
| ov5640_capture | ov_pclk | in | 1 | 像素时钟 |
| | ov_vsync / ov_href | in | 1 | 帧/行有效（高有效） |
| | ov_data | in | 8 | DVP 数据 |
| | pix | out | 16 | RGB565 `{R[4:0],G[5:3],G[2:0],B[4:0]}` |
| | pix_vld | out | 1 | 像素有效（单拍） |
| | cx / cy | out | 10/10 | 像素坐标 |
| | frame_start | out | 1 | VSYNC 上升沿单拍 |

### 3.2 video_out 子系统

| 模块 | 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|---|
| frame_buf | wr_clk / wr_addr / wr_data / wr_en | in | 1/17/16/1 | 写侧（pclk 域，2×2 降采样） |
| | rd_clk / rd_addr / rd_data | in/out | 1/17/16 | 读侧（clk_pix 域，1 拍延迟） |
| vga_timing | x / y | out | 10/10 | 当前像素坐标 |
| | de / hsync / vsync | out | 1 | 显示有效与同步（低有效同步） |

### 3.3 目标表（跨子系统唯一数据契约，M4 起生效）

| 字段 | 位宽 | 说明 |
|---|---|---|
| valid | 1 | 本帧有效 |
| color | 3 | 0=背景 1=红 2=绿 3=蓝 4=黄 5=紫 |
| id | 5 | 跨帧稳定编号 1~31 |
| x0,y0,x1,y1 | 4×10 | 外接框（**块坐标**，显示时 ×4） |
| area | 12 | 块数 |
| tracked | 1 | 是否为当前追踪目标 |

目标表 16 项 × 60bit，双缓冲（当前帧/上帧），写在 clk_sys 域，读在 clk_pix 域 —— 通过"帧结束时整体切换 bank + 2FF 同步切换标志"实现无锁跨域。

## 4. CDC 清单

| 编号 | 跨域信号 | 源→目的 | 手段 | 风险 |
|---|---|---|---|---|
| C1 | pix/pix_vld/cx/cy | ov_pclk → clk_pix（写帧缓存） | 双口 BRAM 独立时钟，天然隔离 | 低 |
| C2 | 块流（块色+luma） | ov_pclk → clk_sys | 异步 FIFO，深度 32 | 中，需验 FIFO 不溢出 |
| C3 | 帧结束标志 | clk_sys → clk_pix | 电平翻转 + 2FF 同步 | 低 |
| C4 | 目标表 bank 切换 | clk_sys → clk_pix | bank 指针 2FF 同步，双缓冲 | 低 |
| C5 | 按键 | clk50 → clk_sys | 2FF + 20ms 消抖 | 低 |
| C6 | MMCM locked | — → 各域 | 作为复位释放条件 | 低 |

**硬规则**：跨域只允许 1bit 电平/脉冲或经 FIFO 的多 bit 总线；多 bit 直接跨域一律视为错误。

## 7. 已知简化（明确记录，不隐藏）

1. 帧缓存采用**点采样** 2×2 降采样（非 2×2 均值），高频细节有轻微混叠。若 M7 有余量可换均值（需 320×16bit 行缓存，+1 BRAM）。
2. 单缓冲存在帧边界撕裂（D1 已确认接受）。
3. `frame_buf` 读地址用 `(x+1)>>1` 预取 1 拍，用以抵消 BRAM 输出延迟，保证框与图像像素对齐。
4. 复位跨域仅做同步释放，未做复位脉冲展宽；上电一次性复位，风险可接受。

# 06 · 自检面板判读（M2 第四轮：从"猜"改为"读")

> 适用位流：`build_flat/ct_top.bit`（含 SCCB 回读自检）
> 现象背景：连续三轮修改寄存器（SCCB 字节格式 → 输出窗口/AEC → DVP 引脚方向），
> 上板现象**完全没变**（始终是 8 色竖条）。这个"改了等于没改"本身就是强证据：
> 寄存器很可能一条都没写进去。写操作无法自证，只能靠读回已知常量来判定。

---

## 1. 为什么加自检

| 手段 | 能证明什么 | 不能证明什么 |
|---|---|---|
| LED1 亮 | 配置序列走完了 | 寄存器是否真的被写入 |
| LED2 亮 | E19 上有边沿 | 边沿是否来自摄像头（悬空脚噪声同样算） |
| LED3 灭 | 每个 ACK 槽 SDA 读到 0 | SDA 恒为低时也读 0 —— **假 ACK** |
| **回读 PID** | 传感器是否在线、SCCB 是否双向通 | 无 |

所以本版新增：**读回 0x300A/0x300B（器件 ID）**，并把它画在屏幕上。

---

## 2. 屏幕布局

没有画面时，屏幕上部显示自检面板（出图后自动切回实时画面）。

```
 vy 0   ┌──────┬─┬─┬─┬─┬─┬─┬─┬─┐   0x300A  PID 高   期望 0x56
 vy 32  ├──────┼─┼─┼─┼─┼─┼─┼─┼─┤   0x300B  PID 低   期望 0x40
 vy 64  ├──────┼─┼─┼─┼─┼─┼─┼─┼─┤   0x3017  PAD 方向 期望 0xFF
 vy 96  ├──────┼─┼─┼─┼─┼─┼─┼─┼─┤   0x3008  电源状态 期望 0x02
 vy128  └──┬───┴─┴─┴─┴─┴─┴─┴─┴─┘
           │  ┌──┐┌──┐┌──┐┌──┐      链路状态四块
           └─▶│  ││  ││  ││  │
              └──┘└──┘└──┘└──┘
```

- 每行最左的方块：**绿 = 与期望值一致**，**红 = 不一致**，**黄 = 还没读回**
- 右侧 8 个小格：该寄存器的 8 个位，从左到右 bit7 → bit0，**白 = 1，深灰 = 0**
- 最下一行四个方块依次为：
  1. SCCB 整体（红 = 出现过 NACK；绿 = 四组读完且无 NACK；黄 = 未完成）
  2. PCLK 是否在跳
  3. HREF 是否出现过高电平
  4. 是否写进过非零像素

## 3. 结果对照表

| 第 0/1 行 | 第 2/3 行 | 链路四块 | 结论 | 下一步 |
|---|---|---|---|---|
| 绿 | 绿 | 全绿 | 传感器在线、配置生效、DVP 有数据 —— 画面本应出现 | 若仍是面板，问题在显示/时序匹配，把位格照片发我 |
| 绿 | 红 | — | **读得通、写没落进去** | 比对第 2 行位格与 0xFF 的差异，判断是地址错还是写时序错 |
| 红 | 红 | — | **SCCB 完全不通** | 见 §4：上拉 / 接触 / 供电 / 器件地址 |
| 黄（一直不读回） | — | — | 读事务卡住 | 量 J18/G20 是否有波形 |

---

## 4. 第 0/1 行为红时的排查顺序

按"最可能且最容易验证"排序：

1. **上拉缺失**（本版已加内部弱上拉兜底）
   SCCB 是开漏总线，主机只能拉低，回高全靠上拉。排针上没有上拉时 SCL 永远回不到高，
   从机收不到时钟。本版已在 XDC 加 `PULLUP true`，并把 SCL 从 195kHz 降到 **97.6kHz**
   以适配弱上拉的慢上升沿。
2. **接触/方向**：摄像头模组是否插到位；排针 J18/G20 是否与模组丝印一致。
3. **供电**：模组 DOVDD/AVDD 是否上电（部分模组需要 3.3V 与 1.8V 两路）。
4. **器件地址**：本设计用 0x78（7 位 0x3C）。若模组把 SID 拉高则地址变 0x7A，
   第 0/1 行会红而链路四块全绿（有 PCLK/HREF）—— 这种情况改 `ct_top` 里两处 `8'h78` 即可。

> 一个容易误判的点：**SDA 恒低时每个 ACK 都能读成 0**，于是 LED3 不亮、`ack_err=0`，
> 看起来"全部 ACK 成功"。这就是为什么必须有回读：只有器件真的驱动 SDA 输出 1，
> 才可能读回 0x5640。

## 5. 本次同时修掉的两个判据缺陷

1. **"有没有画面"不再看 VSYNC**
   上一版以 VSYNC 为帧起点统计非零像素。若 VSYNC 是噪声或缺失，判据会永远停在"没图"，
   即便像素正在写入。本版改为**纯像素计数**（每 4096 个非零像素翻转一次），与 VSYNC 完全解耦。
2. **PCLK 活跃检测用慢速翻转位**
   原计划直接用"每个 PCLK 翻转一次"的信号做两级同步，那在 56MHz 下每拍都变，
   同步器输出近似随机 —— 那不是检测，是噪声。改为每 8192 个 PCLK 翻转一次（约 146us）。

## 6. 复现与验证

```bash
# 读通路仿真（含过程式 OV5640 从机模型）
cd D:/fpga/color_track_ebaz4205/sim
xvlog tb_sccb_rd.v ../rtl/ov5640/sccb_rd.v
xelab tb_sccb_rd -s tb_rd
xsim tb_rd -runall
# 期望：addr 78 / reg 30 0a / read 79 / data 56 / ack_err 0 / PASS
```

仿真在这一轮抓到一个真实缺陷：`S_TXI → S_RX` 跳转时没有清零槽位计数，
导致读阶段一进入就判定"读完"，`rdat` 锁存初值 0。已修复并回归通过。
